About this mod

This mod provides a stylish outfit collection for female V.

  • Includes a crossed top, separate sweater, skirts, and belts.
  • Crafted from wool, net, and black leather textures.
  • Available in nine unique color variations for customization.
  • Supports multiple body types including Angel, EBB, and Vanilla.
  • Obtainable via Tony's Adult Store or manual console codes.

How to install this Cyberpunk

  1. Download the mod archive.
  2. For REDmods: extract to Cyberpunk 2077/mods/ or install via the in-game REDlauncher.
  3. For archive mods: place files in archive/pc/mod/ (create the folder if it doesn't exist).
  4. Some mods require Cyber Engine Tweaks or RED4ext — install those first.
  5. Launch the game and check for conflicts in the mod list.
