About this mod

This mod adds a collection of Miyavi-based hairstyles to Cyberpunk 2077.

  • Includes 32 total hair variants for both male and female characters.
  • Features four core styles including ponytail, wavy, bun, and twist-up.
  • Provides four cap options ranging from full coverage to shaved.
  • Includes new braided base options with integrated hoop accessories.
  • Compatible with Appearance Change Unlocker for custom accessory color editing.

How to install this Cyberpunk

  1. Download the mod archive.
  2. For REDmods: extract to Cyberpunk 2077/mods/ or install via the in-game REDlauncher.
  3. For archive mods: place files in archive/pc/mod/ (create the folder if it doesn't exist).
  4. Some mods require Cyber Engine Tweaks or RED4ext — install those first.
  5. Launch the game and check for conflicts in the mod list.
