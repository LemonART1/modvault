About this mod

This mod adds a dedicated online store for Kriostech clothing and gear.

  • Requires Virtual Atelier to function correctly within the game.
  • Access the store via any in-game computer terminal.
  • Supports Kriostech Military and Sportswear modular outfit collections.
  • Enables remote item purchasing if Virtual Atelier Delivery is installed.
  • Stats will display properly once items are added to inventory.

How to install this Cyberpunk

  1. Download the mod archive.
  2. For REDmods: extract to Cyberpunk 2077/mods/ or install via the in-game REDlauncher.
  3. For archive mods: place files in archive/pc/mod/ (create the folder if it doesn't exist).
  4. Some mods require Cyber Engine Tweaks or RED4ext — install those first.
  5. Launch the game and check for conflicts in the mod list.
