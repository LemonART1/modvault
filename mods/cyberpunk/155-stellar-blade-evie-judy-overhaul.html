About this mod

This mod completely overhauls Judy Alvarez's original design, replacing her with Stellar Blade's Evie. Evie is fully optimized for complete gameplay and photomode support. It features hand-painted 4K full-body skin textures and a customized full-body model and head sculpt. Evie's hairstyle, eyes, makeup, and facial details are completely faithful to the original trailer.

How to install this Cyberpunk

  1. Download the mod archive.
  2. For REDmods: extract to Cyberpunk 2077/mods/ or install via the in-game REDlauncher.
  3. For archive mods: place files in archive/pc/mod/ (create the folder if it doesn't exist).
  4. Some mods require Cyber Engine Tweaks or RED4ext — install those first.
  5. Launch the game and check for conflicts in the mod list.
