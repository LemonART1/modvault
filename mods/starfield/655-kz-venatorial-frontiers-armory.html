About this mod

This mod introduces various Freestar, Ranger, and Bounty Hunter themed spacesuits and outfits to your game. Players can purchase these items from Emerson Shepherd in Akila City or craft custom skins at a spacesuit workbench. The collection includes diverse gear such as helmets, boostpacks, and specialized clothing for your character. It provides a more authentic frontier aesthetic for explorers traversing the settled systems.

How to install this Starfield

  1. Download the mod file.
  2. For standard mods: place files in Starfield/Data/ (create Data if missing).
  3. Add the mod filename to your StarfieldCustom.ini under [Archive] or use a mod manager.
  4. Some mods require Starfield Script Extender (SFSE) — install that first.
  5. For Xbox/Game Pass versions, mod support is limited — check compatibility.
