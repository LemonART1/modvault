About this mod

Native Light is a comprehensive color grading overhaul that removes the washed-out gray veil from Starfield. It replaces generic filters with a neutral base that restores real blacks and honest whites to every environment. The mod includes an optional physics-based planetary system that dynamically colors skies based on atmospheric data. Additionally, it features a completely rebuilt suite of photo mode filters for improved creative capture. This is a lightweight, script-free solution that remains compatible with major weather mods.
