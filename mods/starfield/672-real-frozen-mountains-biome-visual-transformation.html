About this mod

This mod performs a complete visual and weather overhaul of the Frozen Mountains biome. It transforms standard mountain terrain into towering, frigid landscapes with steep snowy slopes. New custom weather patterns create a sense of scale with dynamic fog layers. These changes provide stunning views for explorers and improve the scenery on dozens of planets.

How to install this Starfield

  1. Download the mod file.
  2. For standard mods: place files in Starfield/Data/ (create Data if missing).
  3. Add the mod filename to your StarfieldCustom.ini under [Archive] or use a mod manager.
  4. Some mods require Starfield Script Extender (SFSE) — install that first.
  5. For Xbox/Game Pass versions, mod support is limited — check compatibility.
