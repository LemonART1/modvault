About this mod

Astral UI is a comprehensive, from-scratch overhaul of the inventory, barter, and container menus. It introduces highly customizable subcategories, multi-column item sorting, and advanced quick-loot functionality to improve inventory management. Every column width, text scale, and color theme can be tailored via an extensive configuration file. The mod emphasizes performance and stability while ensuring a clutter-free, efficient user experience for all players.
