About this mod

This mod introduces two new groups of defensible structures to the outpost builder menu. You can utilize dirt-filled military containers and modular walls to construct unique defensive positions. The system features a magnetic snapping feature for easy placement of bunkers and fortifications. It is designed to pair perfectly with the Mercenaries and Mayhem mod to enhance your outpost security.

How to install this Starfield

  1. Download the mod file.
  2. For standard mods: place files in Starfield/Data/ (create Data if missing).
  3. Add the mod filename to your StarfieldCustom.ini under [Archive] or use a mod manager.
  4. Some mods require Starfield Script Extender (SFSE) — install that first.
  5. For Xbox/Game Pass versions, mod support is limited — check compatibility.
