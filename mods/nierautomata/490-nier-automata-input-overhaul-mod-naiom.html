About this mod

This mod resolves common keyboard and mouse input issues in NieR: Automata by providing raw mouse input and removing acceleration. It adds a customizable crosshair for aiming and enables full rebinding of all controls to any key or mouse button. The package includes a user-friendly GUI for sensitivity adjustments and custom cursor support. It is fully compatible with other major community fixes like SpecialK.
