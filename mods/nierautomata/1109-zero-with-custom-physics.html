About this mod

Experience NieR: Reincarnation's Zero within NieR: Automata as a character model replacement for 2B. This mod features fully implemented custom physics, ensuring the character’s cape behaves correctly even during self-destruct animations.

  • Integrates seamlessly with existing DLC Kaine outfits and armor.
  • Includes a dedicated Pod Mikhail model courtesy of Kekoulis.
  • Requires manual installation via the game's data/pl directory.
  • Features a togglable flower effect controlled by the Camouflage Goggles.
  • Built using specialized tools including Nier2Blender2Nier for weight conversion.
