About this mod

This modpack features eight high-quality weapon replacements imported from iconic titles like Bloodborne and Devil May Cry V. Each weapon includes custom menu icons that require the FAR mod to function correctly. The pack is organized into separate folders so you can selectively install your favorite designs. All models and textures have been carefully adapted to fit perfectly within the game world.

How to install this NieR: Automata

  1. Download the mod file.
  2. Many mods require the NieR: Automata Mod Helper or Special K.
  3. Extract files to your NieRAutomata/ game folder following the mod's structure.
  4. For texture/model mods, use the mod manager if provided.
  5. Launch the game and verify the changes appear in the main menu or in-game.
