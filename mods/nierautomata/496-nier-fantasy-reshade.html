About this mod

This mod provides a custom ReShade preset designed to give the game a unique fantasy aesthetic. It enhances the visual depth and color vibrancy of NieR Automata to create a more immersive experience. The package includes customizable depth of field and ambient occlusion settings for fine-tuning. Installation is simple and fully compatible with the FAR mod.

How to install this NieR: Automata

  1. Download the mod file.
  2. Many mods require the NieR: Automata Mod Helper or Special K.
  3. Extract files to your NieRAutomata/ game folder following the mod's structure.
  4. For texture/model mods, use the mod manager if provided.
  5. Launch the game and verify the changes appear in the main menu or in-game.
