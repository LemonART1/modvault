About this mod

This mod allows players to navigate dialogue options and dice rolls using keyboard or controller inputs. It provides full support for custom rebindable keys and gamepad configurations to improve interaction. You can easily manage settings through the integrated mod configuration menu. The mod is fully compatible with existing save files and other modifications.
