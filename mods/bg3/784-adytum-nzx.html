About this mod

This mod provides a virtual textures library for mod dependencies.

  • Prevents engine hard cap issues for virtual textures.
  • Requires Script Extender to process textures correctly.
  • Centralized management tool for developer mod updates.
  • Save game safe for mid-playthrough installation or removal.
  • Compatible with mod managers like BG3MM and Vortex.

How to install this BG3

  1. Download the mod archive.
  2. Use BG3 Mod Manager for easiest installation.
  3. Place .pak files in Baldurs Gate 3/Mods/ and import them in the manager.
  4. Some mods require Norbyte's Script Extender — install that first if needed.
  5. Launch the game through the mod manager to ensure proper load order.
