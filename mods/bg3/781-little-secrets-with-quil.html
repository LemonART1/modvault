About this mod

This mod expands Dark Urge dialogue options during the Quil campfire encounter.

  • Adds confessions of feelings for NPCs like Alfira and Dammon.
  • Removes the specific dismissal line about feelings in the clouds.
  • Requires meeting the NPCs before the Quil camp event triggers.
  • Safe to install or uninstall at any point during playthroughs.
  • Conflicts with mods editing the camp bard backup story file.

How to install this BG3

  1. Download the mod archive.
  2. Use BG3 Mod Manager for easiest installation.
  3. Place .pak files in Baldurs Gate 3/Mods/ and import them in the manager.
  4. Some mods require Norbyte's Script Extender — install that first if needed.
  5. Launch the game through the mod manager to ensure proper load order.
