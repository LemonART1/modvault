About this mod

The Way of Steel is a unique Monk subclass that allows you to wear heavy armor. This build focuses on defense by absorbing melee blows and countering with powerful strikes. You can knock enemies prone to set up attacks for yourself and your allies. It includes custom features for every milestone up to level seventeen.

How to install this BG3

  1. Download the mod archive.
  2. Use BG3 Mod Manager for easiest installation.
  3. Place .pak files in Baldurs Gate 3/Mods/ and import them in the manager.
  4. Some mods require Norbyte's Script Extender — install that first if needed.
  5. Launch the game through the mod manager to ensure proper load order.
