About this mod

This mod adds a new Gunner feat specifically designed for Immersive Firearms and Marksman class mods.

  • Grants proficiency with all firearm weapons.
  • Powerful Shots apply a penalty to target rolls upon a failed save.
  • Increases Dexterity score by +1 up to a maximum of 20.
  • Maneuver save DC scales based on proficiency and ability modifiers.
  • Intended for use with specific firearm and class modifications.

How to install this BG3

  1. Download the mod archive.
  2. Use BG3 Mod Manager for easiest installation.
  3. Place .pak files in Baldurs Gate 3/Mods/ and import them in the manager.
  4. Some mods require Norbyte's Script Extender — install that first if needed.
  5. Launch the game through the mod manager to ensure proper load order.
