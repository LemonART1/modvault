About this mod

This mod allows players to dynamically set the gods of companions, origin characters, and even players using the script extender and MCM menu. It features automatic changes to Lae'zel's deity if she abandons Vlaakith. The mod provides full control over deities, companion presets, and story integration. It is safe to use, has universal compatibility, and can be installed or uninstalled at any point during the playthrough.

How to install this BG3

  1. Download the mod archive.
  2. Use BG3 Mod Manager for easiest installation.
  3. Place .pak files in Baldurs Gate 3/Mods/ and import them in the manager.
  4. Some mods require Norbyte's Script Extender — install that first if needed.
  5. Launch the game through the mod manager to ensure proper load order.
