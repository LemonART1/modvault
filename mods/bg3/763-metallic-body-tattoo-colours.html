About this mod

This mod introduces metallic body tattoo colors for character customization.

  • Utilizes the Draconic Scales slot for tattoo application.
  • Includes both vanilla draconic and face tattoo color options.
  • Requires KAVT and either KaiLimeUI or Rogue Tattoo.
  • Metallic effects apply to both face and body tattoos.
  • Select colors labeled with B to avoid coloring scales.

How to install this BG3

  1. Download the mod archive.
  2. Use BG3 Mod Manager for easiest installation.
  3. Place .pak files in Baldurs Gate 3/Mods/ and import them in the manager.
  4. Some mods require Norbyte's Script Extender — install that first if needed.
  5. Launch the game through the mod manager to ensure proper load order.
