About this mod

Adds a vast collection of new flowers and bushes to Stardew Valley.

  • Includes over 40 flower crops and 5 unique flower trees.
  • Features configurable flower bushes that grow and bloom seasonally.
  • Fully compatible with Content Patcher and supports multiple languages.
  • Provides modular settings for giant crops and color variations.
  • No mandatory requirements, though Generic Mod Config Menu is recommended.

How to install this Stardew

  1. Download the mod.
  2. Install SMAPI (Stardew Modding API) if you haven't already.
  3. Extract the mod into your Stardew Valley/Mods/ folder.
  4. Launch the game through SMAPI (not the default Steam shortcut).
  5. Check the SMAPI console for compatibility warnings on startup.
