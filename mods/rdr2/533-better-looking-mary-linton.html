About this mod

This mod enhances the appearance of Mary Linton by refining her character textures. The result is a cleaner and more polished look for the character throughout the game. You simply need to drag the provided files into your LML stream folder to apply the changes. Ensure you have the Lenny's Mod Loader installed before attempting to use this modification.

How to install this RDR2

  1. Download the mod archive.
  2. Install Lenny's Mod Loader if the mod requires it.
  3. Extract mod files to the appropriate folders in your RDR2 directory.
  4. Some mods use ScriptHookRDR2 — place .asi files in the main game folder.
  5. Always verify game file integrity after removing mods.
