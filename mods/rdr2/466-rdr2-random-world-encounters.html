About this mod

This mod introduces a variety of spontaneous and chaotic ambient events to the Red Dead Redemption 2 game world. NPCs will engage in random fights, robberies, and wildlife attacks that keep the environment unpredictable. Players can customize event frequency and intensity through a configuration file to suit their playstyle. The mod also includes dynamic weather effects and supports interaction with the game's law system.

How to install this RDR2

  1. Download the mod archive.
  2. Install Lenny's Mod Loader if the mod requires it.
  3. Extract mod files to the appropriate folders in your RDR2 directory.
  4. Some mods use ScriptHookRDR2 — place .asi files in the main game folder.
  5. Always verify game file integrity after removing mods.
