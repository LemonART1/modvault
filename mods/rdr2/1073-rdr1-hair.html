About this mod

Recreate John Marston's iconic look by importing his original hair model directly into Red Dead Redemption 2. This port features completely updated UV maps that utilize high-quality RDR2 textures for a modern, crisp appearance.

  • Fully functional vertex paint and weights ensure smooth character interaction.
  • Includes custom LODs to maintain performance during gameplay.
  • The hair model is fully compatible with all in-game hats.
  • Provides a significant visual upgrade over the base game version.
