About this mod

This mod overhauls the mask system to prevent bounty increases and honor changes while you remain unidentified during crimes. It modifies the wanted user interface to display you as an unknown suspect to lawmen. You can use the included configuration file to customize bounty settings and honor behavior to your liking. An optional honor value display can also be toggled on screen for better tracking.
