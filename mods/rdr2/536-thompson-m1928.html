About this mod

This mod replaces the standard bolt action rifle with the iconic Thompson M1928 submachine gun. The weapon features a high level of detail capturing the aesthetic of the 1920s prohibition era. Please note that custom engravings and carvings are not currently supported for this model. For the best performance and stability, users should utilize the Vulkan graphics API as DX12 is not supported.

How to install this RDR2

  1. Download the mod archive.
  2. Install Lenny's Mod Loader if the mod requires it.
  3. Extract mod files to the appropriate folders in your RDR2 directory.
  4. Some mods use ScriptHookRDR2 — place .asi files in the main game folder.
  5. Always verify game file integrity after removing mods.
