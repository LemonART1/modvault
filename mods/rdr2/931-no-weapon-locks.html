About this mod

This script bypasses story-based weapon restrictions by telling the game engine that every purchasable item is already available for purchase. Unlike catalog-editing mods, this does not touch your shop files, which prevents compatibility conflicts with other store modifications.

  • Requires ScriptHook RDR2 V2 to function correctly.
  • Targets the red lock icons found on guns.
  • Maintains compatibility with existing catalog_sp.ymt mods.
  • Does not affect white-locked items restricted by other systems.
  • Features a simple ASI script installation for the main folder.
