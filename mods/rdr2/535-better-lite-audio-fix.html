About this mod

This modification resolves audio issues present in the original mod to allow seamless online audio usage. It ensures compatibility with catalogue improvements and supports additional roles like Bounty Hunting and Moonshiner. You can now experience weapon audio without losing environmental sounds or dialogue lines. Please set this mod to a higher priority than Catalogue Improvements for optimal functionality.

How to install this RDR2

  1. Download the mod archive.
  2. Install Lenny's Mod Loader if the mod requires it.
  3. Extract mod files to the appropriate folders in your RDR2 directory.
  4. Some mods use ScriptHookRDR2 — place .asi files in the main game folder.
  5. Always verify game file integrity after removing mods.
