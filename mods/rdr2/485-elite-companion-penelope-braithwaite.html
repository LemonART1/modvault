About this mod

This mod adds Penelope Braithwaite as a highly capable and deadly combat companion for Arthur. Players can summon and dismiss her using a hotkey and issue commands through a custom menu. The mod features various configuration options including infinite ammo, cinematic kill cams, and specialized combat behaviors. It is recommended to despawn her before starting story missions to avoid potential interference.

How to install this RDR2

  1. Download the mod archive.
  2. Install Lenny's Mod Loader if the mod requires it.
  3. Extract mod files to the appropriate folders in your RDR2 directory.
  4. Some mods use ScriptHookRDR2 — place .asi files in the main game folder.
  5. Always verify game file integrity after removing mods.
