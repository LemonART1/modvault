About this mod

This mod completely overhauls the law enforcement and dispatch response systems throughout the world. It introduces region-specific combat styles, improved AI behaviors for lawmen, and distinct tactical responses from bounty hunters. Criminal investigations are refined with updated bounty mechanics and realistic reactions from both law enforcement and gang factions. The mod also integrates new NPC types, improved interaction dialogue based on player honor, and enhanced environmental perception settings.

How to install this RDR2

  1. Download the mod archive.
  2. Install Lenny's Mod Loader if the mod requires it.
  3. Extract mod files to the appropriate folders in your RDR2 directory.
  4. Some mods use ScriptHookRDR2 — place .asi files in the main game folder.
  5. Always verify game file integrity after removing mods.
