About this mod

Swap out Leon's standard survival gear for the classic red and black tactical suit worn by Deadpool. This mod replaces the default character model entirely, allowing you to experience the campaign with a completely different look. Installation is straightforward using the standard Fluffy Mod Manager interface. Simply drag and drop the provided files into the manager, enable the mod, and launch the game to see the change in-engine. It provides a fun, thematic visual overhaul that fits surprisingly well into the chaotic action of the game.
