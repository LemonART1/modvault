About this mod

This mod replaces standard game charms with unique souvenirs inspired by Ada. It includes optional files to buff charm stats and improve drop rates for higher rarity items. Users playing the Separate Ways expansion should use the provided core add-on for full compatibility. All supported in-game languages feature full translations for these new items.
