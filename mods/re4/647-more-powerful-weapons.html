About this mod

This mod enhances the core weapon arsenal by adjusting stats and functionality for various firearms in the main campaign. It unlocks all weapon upgrades from the start and modifies performance metrics like power, accuracy, and ammo capacity. Rifles now feature regular sights instead of iron sights for improved aiming capabilities. These changes create a more balanced and impactful combat experience throughout your playthrough.

How to install this RE4

  1. Download the mod archive.
  2. Install Fluffy Mod Manager if you haven't already.
  3. Place the mod folder in Fluffy Mod Manager/Games/RE4R/Mods/.
  4. Launch Fluffy Mod Manager, select the mod, and click Launch Game.
  5. Some mods require specific load order — arrange them in the manager if needed.
