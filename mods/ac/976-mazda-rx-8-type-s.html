About this mod

This recreation of the Mazda RX-8 Type-S brings a high level of detail to the track, complete with comprehensive ambient occlusion both inside and out. The interior is fully functional with a realistic dashboard and driver animations that make cockpit views feel authentic.

  • Includes custom CSP settings for improved visual effects.
  • Features tailored physics configurations for a true-to-life driving feel.
  • Performance is optimized with updated LODs and a refined collider.kn5 file.
  • The cockpit has been upgraded to a high-resolution version for better fidelity.
  • Includes a panoramic session start configuration provided by Daniel Nogal.
